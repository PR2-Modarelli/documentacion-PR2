# Documentación del proyecto integrador PR2

Repositorio de documentación y planificación del sistema distribuido de turnos de María Eva Modarelli. Reúne el avance realizado, los próximos pasos y la organización del trabajo para el seguimiento con el profesor.

## Contenido

- [Cronograma y plan](CRONOGRAMA_Y_PLAN.md): trabajo realizado, objetivos por etapas y preparación de las próximas revisiones de código.
- [Lista de issues](ISSUES.md): tareas relacionadas con el cronograma. Es una lista abierta: se pueden agregar issues por errores, inconvenientes o nuevas necesidades.
- [Enunciado original de la cátedra](PROJECT_STATEMENT-v1.md): requisitos del proyecto, conservados sin modificar.
- [Referencia de integración original de la cátedra](INTEGRATION_REFERENCE-v2.md): contratos técnicos de REST, Redis y Kafka, conservados sin modificar.

## Organización

El código se mantiene en los repositorios de catálogo, turnos y Android KMP. Este repositorio concentra la planificación y el seguimiento. El cronograma y las issues se actualizarán según los avances y lo acordado en las reuniones.

El trabajo se organiza con una rama por issue, integración en `develop` y posterior merge a `main` de los bloques validados. Los números reales de las issues se incorporarán cuando se creen en GitHub.

Los dos archivos de la cátedra son material de referencia original; el cronograma y la lista de issues son documentos de planificación del proyecto.
